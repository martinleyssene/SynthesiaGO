3. Son et samples

Les samples ont été implémentés, mais jamais vérifiés (je ne sais pas s’ils jouent réellement).

Méthode : fetch des mp3, decodeAudioData, cache sampleCache[midi]. preloadSamples() charge une note sur trois de 36 à 96, 500 ms après le démarrage.
playNote :
il utilise l’échantillon exact s’il est chargé, sinon le plus proche, avec playbackRate = 2^((midi − midiChargé)/12) ;
le volume décroît jusqu’à 0,001 en 3,5 s, avec arrêt à 3,5 s ;
il n’y a pas de gestion du relâchement de la touche ;
un oscillateur triangle sert de secours.
Réverb : ConvolverNode avec une réponse impulsionnelle synthétique (bruit décroissant sur 2,5 s) et un mélange sec/humide. Le curseur #reverb appelle setReverbAmount, valeur par défaut 0,2.
Source des fichiers : https://gleitz.github.io/midi-js-soundfonts/FluidR3_GM/acoustic_grand_piano-mp3/, avec les noms construits comme Cs4.mp3 (dièses).

Ce n’est pas le Salamander Grand Piano, même si je l’ai appelé ainsi. C’est la banque FluidR3_GM. Je pense que ce dépôt nomme les touches noires avec des bémols (Db4), mais je n’en suis pas sûr. Si c’est le cas, les touches noires donnent un 404 et retombent sur l’échantillon voisin transposé. À tester en regardant l’onglet Network.

6. Format des enregistrements

L’export JSON contient l’objet complet, indenté avec 2 espaces :

json
{
  "id": "rec_1731340000000",
  "name": "Enregistrement du 11/11/2026 18:13",
  "date": "2026-11-11T17:13:00.000Z",
  "notesCount": 42,
  "song": [
    { "time": 1.234, "midi": 64, "duration": 0.5, "hand": "recorded", "color": "#44ddff" }
  ]
}
time et duration sont en secondes. time est relatif au début de l’enregistrement.
midi est le numéro de note MIDI.
hand vaut recorded pour un enregistrement, left ou right pour un MIDI importé.
color est optionnel (hexadécimal) et n’est ajouté que par l’éditeur.
Le stockage se fait dans localStorage, clé piano_recordings_library, sous forme de tableau.
Le format n’a pas changé, hormis l’ajout de color.
L’import vérifie seulement que song est un tableau.
Les couleurs ne sont jamais appliquées à la relecture : spawnNote(midi, hand, duration) ignore color et n’utilise que la classe CSS de hand.
